# Wizards Lineup Lab React v1.1

Changes:
- Real AJ Dybantsa and Felix Okpara images from official NBA Draft assets.
- Removed free dragging from starting-player cards.
- Simplified court to the key, free-throw circle, restricted area, backboard, and rim.
- Removed the inaccurate three-point arc.
- Added preset formations:
  - Balanced
  - 5-Out
  - Horns
  - Box
  - High-Low
- Players remain stationary and reposition automatically when the formation changes.

Run:
npm install
npm run dev
